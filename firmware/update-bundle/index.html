LAN IP / 게이트웨이

적용 후 새 IP로 다시 접속하세요. 메인 공유기 대역이 바뀌면 여기 또는 UDP 툴로 변경합니다.

UDP 발견 토큰

PC 툴 leandns-tool이 같은 LAN에서 이 장치를 찾아 관리 IP를 바꿀 때 사용합니다. (UDP 37421)

켜져 있으면 leandns-tool set --token이 필요합니다. 끄면 같은 LAN에서 토큰 없이 IP를 바꿀 수 있습니다.

설치

          
OpenWrt asus_rt-ac1200-v2 이미지를 ASUS Firmware Restoration으로 기록한 뒤 leandns-manager 패키지를 설치합니다. 자세한 내용은 저장소 docs/installation.md를 참고하세요.

          
메인 공유기 DNS

          
메인 공유기 DHCP에서 DNS를 이 장치의 LAN IP(기본 192.168.0.250)로 지정합니다. LeanDNS는 설치 시 메인 공유기를 자동 변경하지 않습니다.

          
메인 공유기 IP가 바뀌면

          
웹에 접속되면 시스템 메뉴에서 관리 IP, 서브넷 마스크, 게이트웨이를 저장합니다. 웹에 접속되지 않으면 같은 스위치·공유기 LAN에 연결한 PC에서 UDP 37421 브로드캐스트 툴을 사용합니다. 실행 파일은 scripts/build-udp-tool.sh로 만들며 dist/leandns-tool/에 있습니다.

          
Windows 11:

          
leandns-tool-windows-amd64.exe discover

leandns-tool-windows-amd64.exe set --token "웹에표시된토큰" --ip 192.168.34.250 --netmask 255.255.255.0 --gateway 192.168.34.1

          
시스템 메뉴에서 「IP 변경에 토큰 필요」를 끈 경우, Windows 11에서는 --token을 빼도 됩니다.

          
leandns-tool-windows-amd64.exe set --ip 192.168.34.250 --gateway 192.168.34.1

          
Linux:

          
./leandns-tool-linux-amd64 discover
./leandns-tool-linux-amd64 set --token "웹에표시된토큰" --ip 192.168.34.250 --gateway 192.168.34.1

          
토큰 확인이 꺼져 있으면 Linux에서도 set --ip ... --gateway ...만 실행합니다. 직렬 케이블이 없어도 같은 스위치 LAN이면 장치를 찾을 수 있습니다.

          
장애 복구

          
Reset 복구 모드 + ASUS 복구 도구로 factory 이미지를 다시 기록합니다. docs/recovery.md 참고.

          
DNS 우회 / IPv6

          
클라이언트가 DoH를 쓰거나 IPv6 DNS를 직접 쓰면 차단을 우회할 수 있습니다. IPv6 DNS 토글과 클라이언트 DoH 비활성화를 확인하세요.

          
질의 기록

          
상세 DNS 질의 기록은 기본 비활성입니다. 활성화 시 개인정보가 RAM 순환 버퍼에만 남을 수 있습니다.
