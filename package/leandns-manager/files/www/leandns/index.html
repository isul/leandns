            Installation
            
    The reference target is ASUS RT-AC750L (OpenWrt asus_rt-ac1200-v2, 24.10.x). Custom factory images and Windows ASUS Firmware Restoration recovery are for this board (including identical RT-AC1200 V2 hardware). On other OpenWrt 24.10.x devices you can install the leandns-manager package.
    
            
      
              
    1. Set the PC Ethernet to 192.168.1.75/24.
      2. 
              
    2. Power OFF → hold Reset while powering ON → release Reset when the LED blinks slowly.
      3. 
              
    3. Upload the factory image in Firmware Restoration and keep power on until it finishes.
      4. 
            
    
            
    Default LAN IP is 192.168.0.250, gateway 192.168.0.1, DHCP server off. If OpenWrt is already installed (including other devices), install only the leandns-manager package.
    
            
    Initially there is no root password, so you cannot log into the management UI. Connect over SSH first and set a password with passwd.
    
            
    ssh root@192.168.0.250
passwd
    
            
    Then open http://192.168.0.250/ in a browser and log in as root with the password you set.
    
          
    
          
    
            Use ad blocking via DNS settings
            
    Point the main router or each PC/phone DNS at this device's LAN IP (default 192.168.0.250) so lookups go through LeanDNS and ads are blocked. Router settings apply to connected devices; per-device settings limit it to those devices. LeanDNS does not change router or client DNS automatically.
    
          
    
          
    
            Device discovery and management IP change
            
    Discover devices on the same LAN with the commands below. If "Require token for UDP IP changes" is on in System, a token is required; if off, SET works without a token. Apply from the PC or Android tool to change the LAN IP permanently on the device. Then open the web UI at the new address. The Android LeanDNS tool app can discover and configure the same way.
    
            
    Windows
    
            
    leandns-tool-windows-amd64.exe discover
leandns-tool-windows-amd64.exe set --token "YOUR_TOKEN" --ip 192.168.34.250 --netmask 255.255.255.0 --gateway 192.168.34.1
    
            
            
    Linux
    
            
    ./leandns-tool-linux-amd64 discover
./leandns-tool-linux-amd64 set --token "YOUR_TOKEN" --ip 192.168.34.250 --netmask 255.255.255.0 --gateway 192.168.34.1
    
            
          
    
          
    
            Recovery and DNS bypass
            
    If a management IP change expires, reconnect at the previous IP.
    
            
    If SSH works, you can roll back DNS settings.
    
            
    /usr/libexec/leandns/apply-dns.sh --rollback
# or restore a pre-install backup if you have one
cp -a /root/leandns-preinstall-backup/dhcp /etc/config/dhcp
cp -a /root/leandns-preinstall-backup/network /etc/config/network
uci commit && reboot
    
            
    If boot or networking fails: power OFF → hold Reset while powering ON → set the PC to 192.168.1.75/24 → reflash the factory image with ASUS Firmware Restoration.
    
            
    For internet only, set the main router DHCP DNS to 1.1.1.1 (or similar) to bypass LeanDNS. Clients using their own DoH or another IPv6 DNS may skip LeanDNS. Allowing AAAA answers only controls what LeanDNS returns.
