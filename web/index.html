            설치
            
    기준 대상은 ASUS RT-AC750L(OpenWrt asus_rt-ac1200-v2, 24.10.x)입니다. 커스텀 factory 이미지와 Windows용 ASUS Firmware Restoration 복구는 이 보드(동일 하드웨어 RT-AC1200 V2 포함)용입니다. 다른 OpenWrt 24.10.x 기기에는 leandns-manager 패키지를 설치해 사용할 수 있습니다.
    
            
      
              
    1. PC 이더넷을 192.168.1.75/24로 설정합니다.
      2. 
              
    2. 전원 OFF → Reset 누른 채 전원 ON → LED가 느리게 점멸하면 Reset 해제합니다.
      3. 
              
    3. Firmware Restoration에서 factory 이미지를 업로드하고, 끝날 때까지 전원을 유지합니다.
      4. 
            
    
            
    기본 LAN IP는 192.168.0.250, 게이트는 192.168.0.1, DHCP 서버는 꺼져 있습니다. OpenWrt가 이미 있으면(다른 기기 포함) leandns-manager 패키지만 설치하면 됩니다.
    
            
    최초에는 root 비밀번호가 없어 관리 UI에 로그인할 수 없습니다. 먼저 SSH로 접속한 뒤 passwd로 비밀번호를 설정하세요.
    
            
    ssh root@192.168.0.250
passwd
    
            
    설정 후 브라우저에서 http://192.168.0.250/으로 root 계정과 방금 설정한 비밀번호로 로그인합니다.
    
          
    
          
    
            DNS 설정으로 광고 차단 사용
            
    메인 공유기 또는 사용하는 PC·모바일의 DNS를 이 장치의 LAN IP(기본 192.168.0.250)로 바꾸면, 그 기기의 DNS 조회가 LeanDNS를 거쳐 광고를 차단합니다. 공유기에 설정하면 연결된 기기 전반에 적용되고, 기기마다 따로 설정하면 필요한 기기만 사용할 수 있습니다. LeanDNS는 공유기·기기의 DNS를 자동으로 바꾸지 않습니다.
    
          
    
          
    
            장치 검색 및 관리 IP 변경
            
    같은 LAN에서 아래 명령으로 장치를 검색합니다. 시스템 화면에서 「UDP IP 변경에 토큰 필요」가 켜져 있으면 토큰이 필요합니다. 꺼져 있으면 토큰 없이 SET 할 수 있습니다. 적용 뒤 새 IP의 시스템 화면에서 변경을 확정하세요. Android용 LeanDNS 도구 앱으로도 동일하게 검색·설정할 수 있습니다.
    
            
    Windows
    
            
    leandns-tool-windows-amd64.exe discover
leandns-tool-windows-amd64.exe set --token "YOUR_TOKEN" --ip 192.168.34.250 --netmask 255.255.255.0 --gateway 192.168.34.1
    
            
            
    Linux
    
            
    ./leandns-tool-linux-amd64 discover
./leandns-tool-linux-amd64 set --token "YOUR_TOKEN" --ip 192.168.34.250 --netmask 255.255.255.0 --gateway 192.168.34.1
    
            
          
    
          
    
            장애 복구 및 DNS 우회
            
    관리 IP 변경이 만료되면 기존 IP로 다시 접속하세요.
    
            
    SSH가 되면 DNS 설정을 되돌릴 수 있습니다.
    
            
    /usr/libexec/leandns/apply-dns.sh --rollback
# 또는 설치 전 백업이 있으면
cp -a /root/leandns-preinstall-backup/dhcp /etc/config/dhcp
cp -a /root/leandns-preinstall-backup/network /etc/config/network
uci commit && reboot
    
            
    부팅·네트워크가 안 되면 전원 OFF → Reset 누른 채 전원 ON → PC를 192.168.1.75/24로 설정한 뒤 ASUS Firmware Restoration으로 factory 이미지를 다시 올립니다.
    
            
    인터넷만 급하면 메인 공유기 DHCP DNS를 1.1.1.1 등으로 바꿔 LeanDNS를 우회하세요. 클라이언트가 자체 DoH나 다른 IPv6 DNS를 쓰면 LeanDNS를 거치지 않을 수 있습니다. DNS 설정의 AAAA 응답 허용은 LeanDNS가 반환하는 응답만 제어합니다.
